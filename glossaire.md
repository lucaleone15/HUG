# Glossaire de notre produit
## Les différentes entités et instances à préciser
- User
    -> Représente l'admin qui peut se connecter au dashboard et accepter les différentes demandes.
- Trophée
    -> Représente le trophée en soit. On explique donc les conditions pour y participer ainsi qu'une liste des gagnants des années précédentes.
- Label
    -> Représente le label que peuvent gagner les différentes entreprises qui participent au don du sang. Ce label est attribué à toutes les entreprises participantes.
- Kit
    -> Représente le kit de communication qui peut être téléchargé directement sur notre site.
- Quiz
    -> Représente le quiz qui est "l'enquête" passée par les différents protagonistes. Ce quiz permet de déterminer qui peut ensuite s'inscrire au don ou qui est invité à parrainer un collègue en cas de non-éligibilité.
